# Contributing

Thanks for your interest in this project.

## Workflow

1. Fork the repository or create a branch from `main`.
2. Name the branch after the change, for example `feature/add-task-update`.
3. Write the test first, then the code.
4. Run the tests locally with `pytest -v`.
5. Open a pull request. The CI pipeline must be green before merging.

## Commit messages

Use short messages in the imperative mood, for example `Add task update endpoint`.

## Code style

Keep functions small, add type hints, and keep the tests independent of each other.
