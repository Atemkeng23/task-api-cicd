# Security Policy

## Supported versions

Only the latest version on `main` is supported.

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Use GitHub's private vulnerability reporting: Security tab, then "Report a vulnerability".

I aim to acknowledge a report within 7 days.

## Good practices in this repository

- No secrets in the code: `.env` files are ignored by Git.
- Dependencies are kept up to date automatically with Dependabot.
